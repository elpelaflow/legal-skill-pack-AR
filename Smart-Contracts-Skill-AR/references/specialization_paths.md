# Caminos de Especialización

## Posibles v3 futuras

- smart contracts para fintech / pagos;
- escrow comercial;
- DAOs y gobernanza;
- licencias de software on-chain;
- tokenización de activos;
- royalties y revenue share.

## Qué cambiaría una especialización

- taxonomía de riesgos;
- patrones de ejecución;
- oráculos típicos;
- regulación sectorial;
- controles de cumplimiento.
