# Campos del expediente

El borrador debe ordenar, como mínimo:

- identificación del solicitante;
- tamaño de empresa;
- actividad promovida principal;
- descripción técnica breve;
- evidencia técnica resumida;
- proyecto o unidad de negocio alcanzada;
- porcentaje estimado de facturación promovida;
- exportaciones;
- nómina afectada;
- carril principal de requisito adicional recomendado;
- carriles complementarios;
- requisitos adicionales invocados:
  - calidad;
  - capacitación;
  - I+D;
  - exportaciones;
- documentación de respaldo disponible;
- faltantes críticos;
- checklist para carga formal.

El flujo oficial vigente al 21 de mayo de 2026 exige preparación orientada a `Formulario 1278 + TAD`.
