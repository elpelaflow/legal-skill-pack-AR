# Plantillas Sectoriales

## HR / RRHH

Revisar especialmente:

- legajos;
- nómina;
- postulaciones;
- evaluaciones;
- sanciones;
- exámenes preocupacionales si existen.

Base sugerida:

- `Empleados / Candidatos / RRHH`

Riesgo:

- medio o alto si hay datos de salud, sanciones o evaluaciones sensibles.

## Fintech

Revisar especialmente:

- datos de identificación reforzada;
- pagos;
- cuentas bancarias;
- scoring;
- prevención de fraude;
- historial transaccional.

Bases sugeridas:

- `Usuarios / Clientes`
- `Pagos / Facturación`
- `Fraude / Riesgo`

Riesgo:

- alto por datos financieros, fraude y transferencias.

## Healthtech

Revisar especialmente:

- datos de salud;
- diagnósticos;
- telemedicina;
- recetas;
- historia clínica o datos equiparables.

Bases sugeridas:

- `Pacientes / Usuarios Salud`
- `Profesionales de la salud`

Riesgo:

- alto por datos sensibles.

## Videovigilancia

Revisar especialmente:

- cámaras;
- control de accesos;
- grabaciones;
- retention de imágenes;
- proveedores de monitoreo.

Base sugerida:

- `Videovigilancia / Accesos`

Riesgo:

- medio o alto según cobertura y retención.
