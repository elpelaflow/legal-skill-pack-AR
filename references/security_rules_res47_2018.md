# Medidas de Seguridad

## Objetivo

La skill debe producir un plan documental de seguridad razonable y verificable.

## Ejes mínimos

- control de acceso;
- gestión de usuarios y privilegios;
- contraseñas y autenticación;
- backups;
- registro de incidentes;
- gestión de vulnerabilidades;
- cifrado o seudonimización si aplica;
- gestión de dispositivos y endpoints;
- contratos y accesos de terceros;
- baja y retención;
- capacitación;
- respuesta ante incidentes.

## Resultado esperado

No alcanza con una frase genérica del estilo:

`La empresa adopta medidas de seguridad adecuadas.`

La skill debe dejar un esquema operativo:

- medida;
- estado actual;
- evidencia o implementación conocida;
- brecha pendiente;
- prioridad.
