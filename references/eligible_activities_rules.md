# Actividades elegibles y señales

La skill está orientada especialmente a casos de software y servicios digitales.

## Actividades típicas a mapear

- desarrollo de software y servicios informáticos;
- SaaS y plataformas tecnológicas;
- cloud, automatización e infraestructura programable;
- inteligencia artificial, datos y analítica avanzada;
- ciberseguridad;
- soluciones 4.0 con componente técnico demostrable.

## Señales fuertes

- repositorios con producto propio o plataforma para terceros;
- APIs, backend, frontend, integraciones o SDKs;
- despliegue, CI/CD, infraestructura como código;
- módulos de IA, análisis, modelado o automatización;
- documentación técnica, arquitectura y manuales de operación;
- componentes de observabilidad, seguridad o comunicaciones.

## Riesgos

- autodesarrollo para uso interno o para vinculadas como usuario final;
- repositorio vacío o sin tracción técnica;
- narrativa comercial sin soporte en código;
- mezcla de actividad promovida con servicio general no elegible.
