# Reglas de validación

## Semáforo

- `ok`: no se detectaron señales materiales de revisión en esa dimensión.
- `revisar`: hay hallazgos que requieren confirmación o ajuste.
- `critico`: el documento muestra una inconsistencia fuerte o potencialmente engañosa.

## Dimensiones

La skill debe revisar, como mínimo:

1. lenguaje y localización;
2. referencias legales;
3. contexto institucional;
4. formato;
5. PDF final.

## Principio de prudencia

Si la información no alcanza para concluir, marcar `revisar`, no `ok`.
