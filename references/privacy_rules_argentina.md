# Reglas de Privacidad (Argentina)

## Criterio base

La política de privacidad debe explicar de forma entendible:

- qué datos se recolectan;
- para qué;
- con qué base operativa;
- con quién se comparten;
- dónde podrían alojarse;
- cómo puede ejercer derechos la persona usuaria.

## La skill debe marcar especialmente

- datos sensibles;
- biometría;
- geolocalización precisa;
- datos de menores;
- terceros que procesan datos;
- transferencias internacionales;
- conservación y seguridad.

## Regla práctica

Si la app usa datos especialmente sensibles o permisos invasivos, la skill debe elevar el nivel de cautela y no generar un texto minimalista.

## Cautelas reforzadas

- biometría;
- menores;
- geolocalización precisa;
- tracking publicitario;
- datos sensibles;
- permisos móviles invasivos.
