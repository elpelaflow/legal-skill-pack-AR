# Taxonomía de Bases de Datos

## Bases frecuentes

- **Usuarios/Clientes**: cuentas, perfiles, uso del servicio, facturación.
- **Leads/Prospectos**: formularios comerciales, demos, newsletter, CRM.
- **Empleados/HR**: nómina, legajos, candidatos, evaluaciones.
- **Proveedores**: contactos, pagos, contratos.
- **Soporte**: tickets, chats, grabaciones, incidencias.
- **Marketing**: audiencias, campañas, automatizaciones.
- **Analytics**: eventos, identificadores, IP, tracking.
- **Videovigilancia**: cámaras, registros de acceso, imágenes.
- **Pagos / Fraude**: transacciones, antifraude, verificación reforzada.
- **Salud**: pacientes, telemedicina, prestaciones, datos sensibles.

## Regla práctica

No unificar bases distintas solo por comodidad si:

- cambian titulares;
- cambia finalidad;
- cambia origen de datos;
- cambia área responsable;
- cambia retención;
- cambia el nivel de seguridad.
