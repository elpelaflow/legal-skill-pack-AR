# Reglas del Flujo AAIP

## Propósito

La skill debe preparar documentación trazable para:

- relevar tratamientos;
- documentar responsables y bases;
- ordenar medidas de seguridad;
- dejar evidencia para revisión interna o externa.

## Principios

- No inventar tratamientos inexistentes.
- No minimizar categorías de datos sensibles.
- No asumir que un vendor no accede a datos solo porque es SaaS.
- No confundir logs técnicos con datos anónimos si contienen IP, email, identificadores o trazas vinculables.
- No tratar una sola “base” cuando operativamente existen varias finalidades y colectivos diferenciados.

## Regla actual del flujo

La preparación debe separar:

1. **responsable**;
2. **bases de datos**;
3. **medidas de seguridad**;
4. **procedimientos de derechos**.

## Casos de cautela alta

- Datos de salud.
- Datos biométricos.
- Datos de menores.
- Información financiera sensible.
- Videovigilancia.
- Monitoreo intensivo de comportamiento.
- Infraestructura o soporte fuera de Argentina.
- Acceso masivo de terceros o subencargados.

## Criterio para startups y SaaS

La skill debe detectar especialmente:

- base de usuarios/clientes;
- base de leads/comercial;
- base de empleados o postulantes;
- base de proveedores;
- base de soporte;
- base de marketing;
- base de analytics si contiene identificabilidad razonable.
