# Borradores por Base

## Objetivo

Generar una ficha por base de datos para revisión interna y preparación registral.

## Cada ficha debe incluir

- nombre de la base;
- finalidad;
- titulares;
- tipos de datos;
- origen;
- transferencias o terceros;
- conservación;
- observaciones de riesgo.

## Salida

- `RegistroDatosAAIP/Borradores/Base_<NOMBRE>.md`
- `RegistroDatosAAIP/Borradores/BasesRegistro.json`
