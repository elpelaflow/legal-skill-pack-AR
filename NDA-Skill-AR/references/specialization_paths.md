# Caminos de Especialización

## Base actual

La skill actual es horizontal y cubre NDAs generales de negocio y tecnología.

## Posibles v3 futuras

- NDA para due diligence de inversión;
- NDA para M&A o compra de activos;
- NDA para talento / recruiting técnico;
- NDA para intercambio de código o acceso a repositorios;
- NDA con vendors y subprocesadores;
- NDA para IA / datasets / entrenamiento de modelos.

## Qué cambiaría una especialización

- taxonomía de información confidencial;
- excepciones típicas;
- cláusulas reforzadas;
- reglas de acceso a terceros;
- firma y flujo operativo.
