# Escaneo del proyecto

Objetivo: detectar evidencia tecnica util para candidatos de invencion.

- modulos;
- algoritmos;
- reglas o orquestacion;
- seguridad, optimizacion o automatizacion;
- integraciones tecnicas;
- y documentos de arquitectura o diseno.

No confundir feature comercial con solucion tecnica.
