# Plantillas de Productos y Servicios por Clase

Estas plantillas son puntos de partida. No deben copiarse ciegamente.

## Clase 9

Útil para:

- apps descargables;
- software descargable;
- archivos digitales descargables;
- herramientas instalables.

Redacciones base posibles:

- `Aplicaciones de software descargables para [finalidad concreta].`
- `Software descargable para [función específica del usuario].`
- `Programas informáticos descargables para [gestión, análisis, automatización, comunicación, etc.].`

Evitar:

- meter SaaS puro en clase 9;
- usar descripciones abstractas como “software en general”.

## Clase 35

Útil para:

- marketplace;
- retail digital;
- publicidad y marketing;
- administración comercial para terceros.

Redacciones base posibles:

- `Servicios de marketplace para la comercialización de [tipo de productos/servicios].`
- `Servicios de venta minorista en línea relacionados con [tipo de productos].`
- `Servicios de publicidad, marketing digital y promoción comercial para terceros.`
- `Administración comercial de plataformas de venta en línea para terceros.`

Evitar:

- describir desarrollo de software como si fuera clase 35;
- mezclar retail con fintech o SaaS sin separar.

## Clase 36

Útil para:

- pagos;
- billeteras;
- servicios financieros;
- crédito, seguros o inversión.

Redacciones base posibles:

- `Servicios financieros digitales relacionados con [pagos/cobros/transferencias].`
- `Servicios de procesamiento de pagos electrónicos.`
- `Servicios de billetera digital.`
- `Servicios de información y gestión financiera en línea.`

Evitar:

- usar esta clase si el titular solo vende software para entidades financieras y no presta el servicio financiero.

## Clase 41

Útil para:

- educación;
- cursos;
- capacitaciones;
- publicaciones educativas no descargables.

Redacciones base posibles:

- `Servicios de educación y capacitación en [tema].`
- `Organización y dictado de cursos en línea sobre [tema].`
- `Suministro de contenidos educativos no descargables en línea.`

Evitar:

- usar 41 cuando el núcleo del negocio es solo software y no existe servicio educativo real.

## Clase 42

Útil para:

- SaaS;
- PaaS;
- desarrollo de software;
- hosting;
- servicios tecnológicos;
- IA en línea.

Redacciones base posibles:

- `Software como servicio (SaaS) para [función concreta].`
- `Plataforma como servicio (PaaS) para [función concreta].`
- `Desarrollo y mantenimiento de software.`
- `Servicios tecnológicos de alojamiento y provisión de software en línea.`
- `Servicios de inteligencia artificial en línea para [uso concreto].`

Evitar:

- inflar con una lista genérica de buzzwords;
- absorber con 42 actividades que en realidad son 35, 36 o 41.
