# Reglas de Clasificación Niza

## Objetivo

La clasificación debe reflejar la actividad real del solicitante y el alcance que se quiere proteger.

## Principio base

No se clasifica “la empresa”; se clasifican los **productos y servicios identificados con la marca**.

## Clases frecuentemente relevantes para startups y negocios digitales

- **Clase 9**: software descargable, apps descargables, hardware, dispositivos, archivos digitales descargables.
- **Clase 35**: publicidad, marketing, gestión comercial, marketplace, venta minorista o mayorista, comercio electrónico de terceros.
- **Clase 36**: servicios financieros, pagos, billeteras, seguros, inversión, fintech.
- **Clase 38**: telecomunicaciones, transmisión de mensajes, acceso a plataformas de comunicación.
- **Clase 41**: educación, capacitación, publicaciones no descargables, entretenimiento, cursos.
- **Clase 42**: software como servicio (SaaS), plataforma como servicio (PaaS), desarrollo de software, hosting, servicios tecnológicos, IA como servicio.
- **Clase 45**: servicios jurídicos, licencias, seguridad, redes sociales en línea cuando corresponda.

## Errores comunes

- Pedir solo clase 42 cuando el negocio principal es retail o marketplace.
- Pedir clase 9 para software que no se distribuye como descargable.
- Redactar una clase financiera cuando el producto real es solo software para terceros.
- Mezclar en una sola clase servicios que pertenecen a otra.

## Reglas de decisión

- Si el producto es una **app descargable**, evaluar clase 9.
- Si el servicio es **software accesible en línea**, evaluar clase 42.
- Si la marca identifica una **plataforma que intermedia ventas**, evaluar clase 35.
- Si el negocio presta **servicios de pago o finanzas**, evaluar clase 36.
- Si la marca cubre **formación o contenidos educativos**, evaluar clase 41.

## Criterio de redacción

- Usar lenguaje claro y defendible.
- No sobredimensionar alcance sin sustento.
- Agrupar descripciones por clase.
- Si una descripción parece excesivamente amplia, dividirla.
- No usar expresiones como `toda la clase` o equivalentes.
- Según el portal público de Marcas Nuevas del INPI visible al 21 de mayo de 2026, si se consigna `Toda la Clase` o expresiones similares, la solicitud se denegará según Resolución 288/19.
