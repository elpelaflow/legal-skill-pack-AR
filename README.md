# legal-skill-pack-AR 🇦🇷

Pack de **12 skills legales argentinos**. Cada skill vive en su propia subcarpeta, conservando su **historia git completa** (migrados con `git subtree`).

| Skill | Descripción |
|---|---|
| [Knowledge-Economy-Law-Skill-AR](./Knowledge-Economy-Law-Skill-AR) | Derecho de la economía del conocimiento |
| [Legal-Documentation-Validation-Skill-AR](./Legal-Documentation-Validation-Skill-AR) | Validación de documentación legal |
| [NDA-Skill-AR](./NDA-Skill-AR) | Acuerdos de confidencialidad (NDA) |
| [Patent-Application-Preparation-Skill-AR](./Patent-Application-Preparation-Skill-AR) | Preparación de solicitudes de patente |
| [Personal-Data-Registry-Skill-AR](./Personal-Data-Registry-Skill-AR) | Registro de datos personales (Ley 25.326) |
| [Service-Export-Invoicing-Skill-AR](./Service-Export-Invoicing-Skill-AR) | Facturación de exportación de servicios |
| [Skills-Ecosystem-Hub-AR](./Skills-Ecosystem-Hub-AR) | Hub del ecosistema de skills |
| [Smart-Contracts-Skill-AR](./Smart-Contracts-Skill-AR) | Contratos inteligentes |
| [Software-Copyright-Registration-Skill-AR](./Software-Copyright-Registration-Skill-AR) | Registro de derechos de autor de software |
| [Software-Development-Contract-Skill-AR](./Software-Development-Contract-Skill-AR) | Contratos de desarrollo de software |
| [Terms-Privacy-Skill-AR](./Terms-Privacy-Skill-AR) | Términos y condiciones + política de privacidad |
| [Trademark-Registration-Skill-AR](./Trademark-Registration-Skill-AR) | Registro de marcas (INPI) |

## 🛠️ Estructura

Cada subcarpeta es un skill autocontenido (formato `SKILL.md` + documentación + assets).

## 📦 Migración

Los repos individuales fueron unificados en este pack para mantener ordenada la cuenta de GitHub. El historial de cada repo se conservó íntegramente.
