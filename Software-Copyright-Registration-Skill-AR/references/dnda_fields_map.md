# Mapa de campos

Campos tipicos a ordenar:

- nombre de la obra;
- version;
- genero;
- tipo de obra;
- autores;
- titular;
- fecha de finalizacion;
- fecha y lugar de publicacion si aplica;
- descripcion breve;
- categoria del software;
- lenguaje;
- entorno de desarrollo;
- plataforma destino;
- requisitos de hardware orientativos;
- volumen de codigo.
