# Inventario documental

El objetivo de esta etapa es identificar:

- qué archivos existen;
- cuáles son legibles automáticamente;
- cuáles contienen señales jurídicas o formales;
- y cuáles requieren revisión manual.

## Control mínimo

- Listar extensión y ruta relativa.
- Diferenciar documentos editables de PDFs.
- Registrar si el documento tiene texto suficiente para análisis.
- Marcar PDFs con análisis técnico disponible o pendiente.
