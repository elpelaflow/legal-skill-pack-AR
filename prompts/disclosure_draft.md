# Borrador de divulgacion

Construir un esquema de memoria descriptiva con:

- titulo;
- campo tecnico;
- antecedentes;
- problema tecnico;
- resumen de la solucion;
- descripcion de componentes o pasos;
- y posible eje de reivindicacion.

Tiene que leerse como base de trabajo para revision profesional, no como presentacion final cerrada.
