# Caminos de Especialización

## Base actual

La skill actual es horizontal. Sirve para muchos productos digitales distintos.

## Cuándo conviene especializar

- cuando un vertical se repite muchas veces;
- cuando siempre aparecen las mismas cláusulas especiales;
- cuando la skill general ya no da suficiente precisión;
- cuando el riesgo regulatorio del sector es alto.

## Ejemplos de especialización

### Ecommerce

- pagos;
- devoluciones;
- promociones;
- fraude;
- cuentas.

### Marketplace

- intermediación;
- terceros oferentes;
- disputas;
- pagos;
- reportes y baja de cuentas.

### Healthtech

- datos sensibles;
- salud;
- geolocalización;
- vendors clínicos;
- permisos móviles sensibles.

### Edtech

- menores;
- cuentas educativas;
- actividad de alumnos;
- contenidos.

### Comunidad / red social

- contenido generado por usuarios;
- moderación;
- denuncias;
- suspensión;
- propiedad intelectual del contenido.
