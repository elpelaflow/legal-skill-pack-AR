# Evidencia técnica

Construí una matriz con:

- actividad promovida sugerida;
- evidencia observada;
- archivos, módulos o documentos fuente;
- nivel de fuerza probatoria;
- vacíos a completar.

La evidencia debe ser trazable.

No alcanza con decir:

- "usa IA";
- "es cloud";
- "es software escalable".

Hay que mostrar señales concretas:

- librerías;
- módulos;
- APIs;
- automatizaciones;
- pipelines;
- documentación técnica;
- infraestructura como código;
- integraciones productivas.
