# Mapeo de elegibilidad

Objetivo: determinar si el proyecto tiene señales compatibles con actividades promovidas.

Preguntas guía:

- ¿El código demuestra desarrollo de software o servicios informáticos por cuenta propia?
- ¿Hay cloud, automatización, IA, analítica, ciberseguridad o soluciones 4.0?
- ¿El proyecto es producto para terceros o autodesarrollo para uso propio?
- ¿La evidencia técnica está en código, documentación, pipelines, APIs o despliegues?

El mapeo debe:

- distinguir actividad promovida de mera operación interna;
- separar evidencia técnica de afirmaciones comerciales;
- marcar riesgos de autodesarrollo;
- dejar explícitas las actividades sugeridas y las descartadas.
